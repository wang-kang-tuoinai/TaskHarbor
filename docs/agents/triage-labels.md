# 任务分诊标签

| Skill 角色 | 跟踪系统标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由 Agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

Skill 提及分诊角色时，使用对应标签。这些状态仅用于开发任务，不用于 ADR 或平台任务生命周期。
