# ADR-0003：执行监督、资源归属与分阶段生命周期

- 状态：已接受
- 日期：2026-11-02
- 关系：补充现有执行生命周期设计，不替代 ADR-0001。

## 背景

Handler 可能不响应取消，监督流程需要能够先处理超时而不被 Handler 阻塞。Handler 实际退出、停止续租和结果上报结束是不同事件，混用执行表或执行槽判断结束，会导致并发超限、继续续租超时任务，或退出时漏等结果上报。

## 决策

### 执行监督与资源归属

1. 监督协程与 Handler 协程分离。Handler 协程恢复 panic，并通过容量为 1 的结果 channel 发送一次完整结果，成功也发送；Handler 实际退出时恰好归还一次执行槽。
2. 超时、abort 或监督协程退出不提前释放仍存活 Handler 的槽。监督协程可以先结束，迟到结果不会阻塞 Handler，也不会触发第二次结果上报。
3. 执行超时在紧邻 Handler 启动处建立，不计入 Claim 和本地登记准备时间。结果与超时同时就绪时，接受监督协程选择其中一个分支，不承诺按真实发生先后裁定。
4. executions 表表示仍需要续租的执行尝试，按 taskID 与 attemptToken 区分轮次。正常 Handler 返回后，结果上报结束前仍保留记录并续租；上报成功、明确拒绝或重试耗尽后移除。超时、明确失权或强制取消先移除记录并发出取消，再按相应分支处理。
5. 执行表为空不证明所有 Handler 或上报流程已结束。完整退出实现需要分别等待 Handler 与监督流程。
6. abort 采用关闭 channel 的广播语义，由唯一的生命周期管理方负责关闭，不能用发送一条消息通知所有监督协程。监督协程必须响应 abort；取消信号不表示业务代码已退出。

### 已确认、延期实现的完整退出语义

1. Start 非阻塞。未来 Shutdown(ctx) 先停止新领取，维持已有任务的执行、续租和结果上报，并等待排空。
2. 正常排空时，已经发出的 Claim 若明确成功，纳入排空并执行；进入强制取消阶段后，不再启动新 Handler，不退回已授予的尝试次数。
3. 排空期限到达时，请求取消未完成 Handler、停止其续租，对没有确定结果的任务保留 Redis 状态供租约回收，并返回超时错误。不能声称所有 goroutine 已退出。
4. Errors() 提供容量为 1 的只读错误 channel，供单个调用方接收导致领取停止的致命错误。不得因无人读取而阻塞停止流程；空队列和可恢复网络波动不作为致命错误持续发送。已有任务继续执行，由调用方决定排空处理。
5. Server 对象不支持重启。故障排除后创建新实例。

### 本轮实施边界

- 本轮 Start 仅接入 beginStart 和 Claim 协程，不实现完整 Shutdown、停止领取接口或排空流程。
- 实现本地执行监督及 abort 响应，但本轮尚无公开退出入口；不能将已预留 abort 描述为已实现服务退出。
- complete 与 ReportFailure 暂用内部空方法占位，不执行 Redis 迁移，也不得把调用占位方法当作真实上报成功。真实接口、错误和重试细节留待相应设计讨论。
- Renew 专用协程、Reclaim 和真实结果上报延期。执行表关于续租的规则是后续接入约束，本轮没有实际续租行为。
- Issue 数量、临时方法签名和轮询数值属于实施计划，不单独作为架构决策。

## 后果与限制

- 不响应 context 的 Handler 可能在监督结束后继续运行并产生业务副作用；仍占用执行槽。
- 移除执行记录无法撤回已经发出的 Renew。未来接入续租后，已在途的一次 Renew 仍可能成功并延后回收；第一版不增加复杂串行化机制来消除此窗口。
- 正常 Handler 退出后槽可释放，但上报仍可能在途，因此完整 Shutdown 不能只等槽或执行表。
- 本轮没有 Renew，长任务租约可能到期而 Handler 仍运行；没有 Reclaim，租约到期不会自动迁移状态；上报占位意味着 Handler 返回后任务仍可能保持 running。此阶段不是完整、可投入使用的任务服务。
- 取消通知先于登记、迟到 Claim 响应及本地租约到期保护仍沿用现有已知限制，不因本决策视为解决。

## 替代方案

- 监督协程结束即释放槽：拒绝，可能在旧 Handler 存活时不断启动新任务，突破并发限制。
- Handler 与监督放在同一协程：不采用，无法在 Handler 阻塞时独立处理超时和 abort。
- 以执行表为空作为退出条件：拒绝，遗漏已停止续租但仍存活的 Handler 或在途处理。
- Start 阻塞并直接返回后台错误：不采用，选择非阻塞 Start 与独立 Errors 通知。
- 本轮一次实现续租、回收、上报和完整退出：不采用，相关内部细节尚未充分讨论，按阶段推进。

## 实现与文档状态

现有代码只有 Server 本地基础结构，尚未实现以上运行流程。Claim 契约已有执行槽和超时基本约束，本 ADR 细化其本地资源归属与未来退出行为；后续实施前按实际范围同步相关契约。ADR 接受不代表功能验收完成。
